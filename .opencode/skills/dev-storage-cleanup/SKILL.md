# Dev Storage Cleanup (Orbit)

Orbit is a Tauri + Rust project. **Most dev disk usage is expected** and comes from
incremental Rust builds, not from source code.

## What usually consumes space

| Location                                                              | Typical size | Safe to delete?                                 |
| --------------------------------------------------------------------- | ------------ | ----------------------------------------------- |
| `apps/desktop/src-tauri/target/`                                      | **5–15+ GB** | Yes — `cargo clean` (full rebuild next compile) |
| `node_modules/`                                                       | ~200 MB      | Reinstall with `bun install`                    |
| `apps/desktop/dist/`, `apps/landing/.next/`, `.nx/cache/`, `release/` | small        | Yes — regenerated by build                      |
| `test-results/`, `playwright-report/`                                 | small        | Yes                                             |
| `~/Library/Application Support/Orbit/orbit.sqlite3*`                  | ~10–50 MB    | **No** — live library + settings                |
| `~/Library/Application Support/Orbit/steam-windows/`                  | large        | **No** — signed-in Windows Steam prefix         |
| `~/Library/Application Support/Orbit/{artwork-cache,themes,runtimes}` | varies       | **No** — user artwork, themes, compatibility    |
| `orbit.sqlite3-wal`                                                   | varies       | Checkpoint only when Orbit is **quit**          |
| `~/.cargo/registry`                                                   | ~200 MB–2 GB | Prune with `cargo cache -a` (--deep)            |
| `~/.bun/install/cache`                                                | ~100 MB–1 GB | `bun pm cache rm` (--deep)                      |
| `~/Library/Caches/ms-playwright`                                      | ~500 MB–2 GB | Re-download on next e2e                         |

**Not Orbit:** GameHub testing creates large data under
`~/Library/Application Support/com.gamemac.www/` (wine-engine, Steam depots). That is
separate from Orbit.

## Workflow

### 1. Report (always first)

```bash
bun run clean:report
# or: node scripts/cleanup-dev-storage.mjs
```

Summarize findings for the user: highlight `apps/desktop/src-tauri/target/` first.

### 2. Safe project cleanup (default)

```bash
bun run clean
```

This runs `cargo clean` and removes `apps/desktop/dist/`, `apps/desktop/test-results/`,
`apps/desktop/playwright-report/`, `apps/desktop/playwright/.cache/`, `apps/landing/.next/`,
`.nx/cache/`, and `release/`. **Does not** touch `node_modules`, Application Support
Orbit data (`steam-windows`, sqlite, themes), or global caches.

Warn the user: next Rust build will be slower.

### 3. Deep cleanup (only when user agrees)

```bash
bun run clean:deep
```

Also runs `bun pm cache rm` and `cargo cache -a` (requires `cargo-cache` crate).
Never delete `~/Library/Application Support/Orbit/` (including `steam-windows/`)
without an explicit user request to reset Orbit data. See
`.cursor/rules/preserve-user-data.mdc`.

### 4. SQLite WAL (optional, Orbit quit)

If `orbit.sqlite3-wal` is large and Orbit is not running:

```bash
sqlite3 ~/Library/Application\ Support/Orbit/orbit.sqlite3 'PRAGMA wal_checkpoint(TRUNCATE);'
```

### 5. Prevent recurrence (recommendations)

- Run `bun run clean` after heavy Tauri/Rust work or before archiving the repo
- Add `apps/desktop/src-tauri/target/` to Time Machine exclusions if backups are huge (already gitignored)
- Prefer `bun run tauri:build` over repeated debug builds when testing release-only issues
- Keep Playwright browsers only if running e2e regularly

## Agent checklist

1. Run `bun run clean:report` and show the table to the user
2. Call out the largest path (almost always `apps/desktop/src-tauri/target/debug`)
3. Run `bun run clean` unless the user only wanted a report
4. Use `bun run clean:deep` only for global cache bloat **and** with user awareness
5. Do **not** remove Application Support Orbit data, `steam-windows`, or the live SQLite file unless the user explicitly asks to reset Orbit data
6. Mention GameHub/wine-engine if `com.gamemac.www` is larger than Orbit artifacts
