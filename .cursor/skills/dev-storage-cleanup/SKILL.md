# Dev Storage Cleanup (Orbit)

Orbit is a Tauri + Rust project. **Most dev disk usage is expected** and comes from
incremental Rust builds, not from source code.

## What usually consumes space

| Location                                             | Typical size | Safe to delete?                                 |
| ---------------------------------------------------- | ------------ | ----------------------------------------------- |
| `src-tauri/target/`                                  | **5–15+ GB** | Yes — `cargo clean` (full rebuild next compile) |
| `node_modules/`                                      | ~200 MB      | Reinstall with `yarn`                           |
| `dist/`, `release/`                                  | small        | Yes — regenerated by build                      |
| `test-results/`, `playwright-report/`                | small        | Yes                                             |
| `~/Library/Application Support/Orbit/orbit.sqlite3*` | ~10–50 MB    | **No** — user library DB (artwork as Base64)    |
| `orbit.sqlite3-wal`                                  | varies       | Checkpoint only when Orbit is **quit**          |
| `~/.cargo/registry`                                  | ~200 MB–2 GB | Prune with `cargo cache -a` (--deep)            |
| `~/Library/Caches/Yarn`                              | ~100 MB–1 GB | `yarn cache clean` (--deep)                     |
| `~/Library/Caches/ms-playwright`                     | ~500 MB–2 GB | Re-download on next e2e                         |

**Not Orbit:** GameHub testing creates large data under
`~/Library/Application Support/com.gamemac.www/` (wine-engine, Steam depots). That is
separate from Orbit.

## Workflow

### 1. Report (always first)

```bash
yarn clean:report
# or: node scripts/cleanup-dev-storage.mjs
```

Summarize findings for the user: highlight `src-tauri/target/` first.

### 2. Safe project cleanup (default)

```bash
yarn clean
```

This runs `cargo clean` and removes `dist/`, `test-results/`, `playwright-report/`,
`release/`, `playwright/.cache/`. **Does not** touch `node_modules`, app DB, or global caches.

Warn the user: next Rust build will be slower.

### 3. Deep cleanup (only when user agrees)

```bash
yarn clean:deep
```

Also runs `yarn cache clean` and `cargo cache -a` (requires `cargo-cache` crate).
Never delete `~/Library/Application Support/Orbit/` without explicit user request.

### 4. SQLite WAL (optional, Orbit quit)

If `orbit.sqlite3-wal` is large and Orbit is not running:

```bash
sqlite3 ~/Library/Application\ Support/Orbit/orbit.sqlite3 'PRAGMA wal_checkpoint(TRUNCATE);'
```

### 5. Prevent recurrence (recommendations)

- Run `yarn clean` after heavy Tauri/Rust work or before archiving the repo
- Add `src-tauri/target/` to Time Machine exclusions if backups are huge (already gitignored)
- Prefer `yarn tauri:build` over repeated debug builds when testing release-only issues
- Keep Playwright browsers only if running e2e regularly

## Agent checklist

1. Run `yarn clean:report` and show the table to the user
2. Call out the largest path (almost always `src-tauri/target/debug`)
3. Run `yarn clean` unless the user only wanted a report
4. Use `yarn clean:deep` only for global cache bloat **and** with user awareness
5. Do **not** remove Application Support Orbit data unless asked
6. Mention GameHub/wine-engine if `com.gamemac.www` is larger than Orbit artifacts
